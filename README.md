暖心血压通 - 独居老人智能血压监测系统
面向独居高血压老人的轻量级网页血压监测Demo，纯前端实现，打开浏览器即可使用。
项目简介
针对独居老人日常测量血压时"记录难、判断难、家属远程知晓难"三大痛点，设计的适老化网页工具。系统根据老人年龄、测量时段自动调整血压判断阈值，将数据保存为直观表格和趋势折线图，并同时输出给老人的温和建议和给家属的风险提示。

使用方法
方式一：直接打开（最简单）
1. 下载 blood-pressure-demo.html 到本地
2. 双击文件，系统默认浏览器会自动打开
3. 即可开始使用全部功能
方式二：VSCode + Live Server（开发推荐）
1. 用VSCode打开项目所在的文件夹（不要只打开单个文件）
2. 安装 Live Server 插件
3. 右键 blood-pressure-demo.html → Open with Live Server
4. 浏览器自动打开 http://localhost:5500/blood-pressure-demo.html
方式三：命令行启动临时服务
# Python 3 环境下，在文件所在目录执行
python -m http.server 8080

# 浏览器访问
# http://localhost:8080/blood-pressure-demo.html
快速上手操作
1. 填写基本信息：输入老人姓名和年龄（年龄用于智能判断阈值）
2. 录入血压：测量血压计上的高压（收缩压）和低压（舒张压），点击「记录本次血压」
3. 查看结果：页面自动显示血压等级（绿/黄/红三色）和双视角建议
4. 查看趋势：向下滚动可看到血压变化折线图和历史记录表格
5. 切换家属模式：点击顶部「家属模式」，可查看总测量次数、正常/异常次数统计
核心实现说明
1. 血压判断逻辑（judgeBloodPressure 函数）
- 基础标准：参考《中国高血压防治指南》的血压分级
- 年龄修正：65岁以上放宽收缩压上限，80岁以上进一步放宽
- 时段修正：清晨6:00-10:00血压晨峰时段，判断阈值自动上浮10mmHg
- 返回值：等级名称、颜色样式、判断描述，供UI层渲染
2. 数据存储（LocalStorage）
- 存储键名：blood_pressure_records
- 数据格式：JSON数组，每条记录包含时间戳、高压、低压、年龄
- 新记录unshift到数组头部，表格和图表按时间倒序展示
3. 趋势图（ECharts）
- 两条折线：收缩压（深棕色粗线）、舒张压（浅棕细线）
- markArea 标记90-140mmHg正常范围绿色色带
- 窗口resize时自动重绘，适配响应式

注意事项
1. 本Demo为健康管理辅助工具，不构成医疗诊断，血压明显异常请及时就医
2. LocalStorage数据绑定在当前浏览器，清除浏览器缓存会丢失记录
3. ECharts通过CDN加载，首次打开需要联网；离线环境需下载echarts.min.js到本地
